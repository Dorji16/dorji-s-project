# 3D Printing!!
## Introduction.
 ## What is 3D Printing?

 3D Printing is a process of creating 3D objects from a digital file by depositing layers of material.The object is formed by adding material layer by layer until the final shape is completed.

 ## My Journey with 3D Printing

I started my journey in 3D printing for the first time. Initially, I thought that I wouldn't be able to do it because, at first glance, it looked very complicated and difficult to learn.

However, after sir taught us the whole process, I realized that 3D printing is not that hard to learn.

## Process

## Step 1: Open PrusaSlicer
Launch PrusaSlicer on your computer.

## Step 2: Select Your Printer

In the top-right corner, select the following:

Printer: Prusa i3 MK3
Filament: PLA (or your preferred material)
Print Settings: 0.20mm QUALITY

## Step 3: Import Your 3D Model

Import your 3D model using one of the following methods:

Click File → Import → Import STL/3MF/OBJ
Drag and drop the .stl file into the build area

4. Position the Model: Use the tools on the left toolbar:


## Recommendation

Keep the model flat on the print bed for better adhesion and print quality.

5. Configure Print Settings
Layer Height

Choose the layer height:
Infill
15–20% for normal parts
Higher for stronger parts
Supports: use if your model has large overhangs.

6. Slice the Model

Click the Slice Now button located in the bottom-right corner.

During slicing, PrusaSlicer will:

Generate print layers
Create toolpaths
Estimate print time
Calculate filament usage

7. Preview the Slice
After slicing, click Preview.

Use the vertical slider to inspect the print layer by layer.

## Check the Following:
Support structures
Infill pattern
Outer walls
First layer quality

8. Export G-code
Click Export G-code and save the file to:
a.SD card
b.USB drive


9. Print on the Prusa i3 MK3
## Printing Steps:
a. Insert the SD card into the printer
b. Select Print from SD
c. Choose the exported .gcode file
d. Start the print

## The printer will automatically:

1. Heat the nozzle and print bed
2. Perform bed leveling
3. Begin printing layer by layer
4. Recommended Beginner Settings
## Setting	Recommended Value
1. Layer Height	0.20 mm
2. Infill	15%
3. Supports	Only if needed
4. Nozzle Temperature (PLA)	215°C
5. Bed Temperature (PLA)	60°C
## Helpful Tips
1. Clean the print bed before each print
2. Monitor the first layer carefully
3. Use PLA material when starting with 3D printing
4. Keep models centered on the print bed
5. Avoid unnecessary supports to reduce print time and material usage
